# MILO MENU — لوحة إنشاء منيو إلكتروني

مشروع عربي متجاوب مكوّن من لوحة دخول وإدارة منفصلة عن صفحة المنيو العامة. كل تاجر لديه حساب خاص، وينشئ قوائم طعام متعددة، ويضيف الأقسام والمنتجات والأسعار وروابط الصور ويصدر رابطًا عامًا ورمز QR لكل منيو. تعديل الأسعار يظهر في الرابط العام فور حفظه في قاعدة البيانات.

## الملفات
- `index.html` الواجهة ولوحة التحكم وصفحة الزبون
- `style.css` التصميم المتجاوب
- `app.js` وظائف التطبيق وربط Firebase
- `firebase-config.js` إعدادات الاتصال التي تضعها مرة واحدة
- `firestore.rules` قواعد أمن قاعدة البيانات

## الإعداد لأول مرة (ضروري قبل أن تعمل الروابط العامة)
1. أنشئ مشروعًا مجانيًا في https://console.firebase.google.com/ .
2. داخل **Authentication → Sign-in method** فعّل **Email/Password**.
3. داخل **Firestore Database** أنشئ قاعدة بيانات (وحدد منطقة مناسبة؛ لا تحتاج لبدء وضع الاختبار).
4. افتح **Firestore Database → Rules** والصق محتوى `firestore.rules` واضغط Publish.
5. من **Project settings → Your apps** أضف تطبيق Web وانسخ قيم `firebaseConfig` إلى `firebase-config.js` بدل القيم `PUT_...`.
6. داخل **Authentication → Settings → Authorized domains** أضف نطاق موقعك المنشور، إن لم يكن موجودًا.
7. ارفع جميع الملفات إلى مستودع GitHub، ثم Settings → Pages → Deploy from a branch → main / (root).
8. افتح رابط GitHub Pages، أنشئ حساب تاجر، أنشئ منيو، فعّل «المنيو منشور» واضغط «حفظ التعديلات». سترى رابط المنيو وQR.

> لا يكفي فتح `index.html` بالنقر المزدوج من الجهاز؛ استخدم استضافة HTTPS مثل GitHub Pages. إعداد Firebase مطلوب لحفظ بيانات مشتركة بين الأجهزة. يجب اختبار الصلاحيات قبل استخدامه مع عملاء حقيقيين.

## حدود النسخة
- الصور تُضاف باستخدام **روابط HTTPS** عامة، دون رفع ملفات داخل النظام. يمكن تطوير رفع الصور لاحقًا باستخدام Firebase Storage وسياسات أمان مناسبة.
- رمز QR يُولّد عبر خدمة `api.qrserver.com`، وهذا يرسل **رابط المنيو العام فقط** إلى الخدمة؛ لا ترسل معلومات شخصية في عنوان المنيو.
- لا يوجد دفع إلكتروني أو طلبات أو اشتراكات وفواتير للتجار في هذه النسخة.
- القوائم غير المنشورة لا يراها الزائر. صاحب الحساب وحده يستطيع تعديل قوائمه وفق القواعد.
- رابط القائمة على شكل `https://your-site.github.io/?menu=m-xxxxxxxxxxxxxxxx`، وليس نطاقًا منفصلًا لكل تاجر.
- واجهة المعاينة تعرض القوائم، لكن التنقل عبر تبويبات الأقسام متاح في صفحة المنيو العام.
- قم بتفعيل حصص الميزانية والتنبيهات على مشروع Firebase قبل فتح الخدمة على عدد كبير من المستخدمين.

## اختبار سريع
1. من حساب التاجر أضف قسمًا ومنتجين ثم انشر.
2. انسخ الرابط وافتحه من نافذة خاصة أو هاتف آخر بدون تسجيل دخول.
3. غيّر سعر منتج ثم اضغط حفظ وأعد تحميل الرابط للتحقق من التحديث.
4. ألغِ النشر واحفظ؛ يجب أن تظهر رسالة عدم إتاحة للزائر.
5. سجّل بحساب تاجر آخر؛ يجب ألا يرى أو يستطيع تعديل قوائم التاجر الأول.
